## 二、功能验证（真机实测）

### 多模型擂台
- 入口：对话首页快捷入口「擂台」（第 5 个）。
- 实测：`free / openrouter-free-router` vs `DeepSeek / Flash` 并排流式，两栏各自显示 **首字延迟 / tokens / 费用**（免费侧 ¥0.00）；合计 token 显示在标题下。
- 投票「A 更好 / 平局 / B 更好」落库（`arena_runs.winner = 'TIE'` 已验证），历史列表显示对应标签，长按可删。
- 单侧失败只影响该侧；停止后已出字的一侧保留为可回看内容。
- 截图：`docs/smoke/05-arena.png`、`07-arena-run.png`、`08-arena-voted.png`。

### 会话分支
- 用户消息长按 →「编辑并分支」→ 弹窗预填原文 → 发送后在原父节点下生成新分支，原回答完整保留。
- 用户消息与助手消息都显示 `‹ 2/2 ›` 切换器，实测 1/2 ↔ 2/2 双向切换正常，历史随之变化。
- DB 校验：conv 7 的两条用户消息 (33, parentId 0) 与 (96, parentId 0) 为兄弟，`leafMessageId` 随切换移动。
- 导出 Markdown/HTML 只导出激活路径；ZIP 备份保留整棵树（新增 `parentId` / `leafMessageId` 字段，老备份缺字段按单链重建）。
- 截图：`docs/smoke/14-branch-dialog.png`、`17-branch-switcher.png`、`18-branch-prev.png`。

### AI 自动标题
- 首轮回复结束后异步生成，2–12 秒内把「首条消息截断标题」替换为语义标题。
- DB 校验：conv 19 标题由 `What is a vector database` → **「什么是向量数据库」**；conv 13/16 因思考型模型首轮超时保留了截断标题（不覆盖，属预期降级）。

- 截图：`docs/smoke/26-list.png`。

## 三、实测暴露并修复的缺陷

| # | 现象 | 根因 | 修复 |
|---|---|---|---|
| 1 | 思考型模型的擂台「首字」恒显示「—」 | 只在正文增量到达时计时 | 思考增量也算首个 token |
| 2 | 编辑分支后看不到切换器 | 切换器只挂在助手消息上 | 用户消息也渲染，且用 `hasTree` 区分老数据 |
| 3 | 自动标题从不触发 | 生成流程已把标题写成「首条消息截断」，`needsTitle` 只认空串 | 新增 `needsTitle(current, firstUserText)`，把派生的截断标题也视为未命名 |
| 4 | 自动标题在这类模型上整轮空返回 | 48 token 预算被思考吃光 | 预算提到 256，并把思考最后一行作为兜底标题来源 |
| 5 | 自动标题 8 秒超时 | 豆包 Seed 2.1 Turbo 实测需 11.9 秒 | 超时放宽到 20 秒（仍在后台，不阻塞对话） |
| 6 | 1.2 遗留：图片翻译记录页引用缺失资源 | 缺 `photo_record_no_image` / `photo_record_retake` 与 `PaddingValues` import | 补齐资源与 import |

另有两条 1.3 输入框改造引入的缺失文案（`composer_expand` / `composer_collapse` / `composer_char_count`）已按对方设计补齐中英文。

## 四、架构与数据

- Room **v5 → v6**：`messages.parentId`（+ 索引）、`conversations.leafMessageId`、`arena_runs`、`arena_outputs`。
- 迁移回填：按 `(createdAt, id)` 把老会话串成单链，`leafMessageId` 指向每个会话最后一条消息；已用 SQLite 实测验证。
- 新增接缝：`ArenaRepository`（独立仓库，不写 messages）、`AutoTitler`（回合后置钩子）、`UsageStats`（只读聚合）、`BranchPath`（纯函数消息树）。
- 纯逻辑全部脱离 Android，可单测：`AutoTitle`、`BranchPath`、`ArenaTally`、`UsageAgg`、`FaceDirection`。

## 七、遗留与后续

- 面对面模式的同传流是单向的：换方向会重启这一段流（UI 已提示），不是「说着说着自动翻面」。
- 擂台历史保留最近 50 局，超出自动淘汰。
- 自动标题在思考型模型上可能要 12–20 秒才出现（异步，不影响对话）。
- 老备份导入后是单链（无分支），这是兼容取舍。
